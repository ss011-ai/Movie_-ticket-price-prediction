# 🎬 Movie Ticket Price Prediction

This project is a Machine Learning-based application that predicts movie ticket prices based on input features. It helps understand pricing patterns using data analysis and ML models.

---

## 🚀 Features
- 🎯 Predict movie ticket prices  
- 🤖 Machine Learning model  
- 📊 Data analysis & visualization  
- 🌐 Streamlit web app interface  

---

## 📁 Project Structure
Movie_Ticket_Price_Prediction/
│
├── app.py # Streamlit web application
├── requirements.txt # Required libraries


---

## 🛠️ Tech Stack
- Python 🐍  
- Pandas  
- NumPy  
- Scikit-learn  
- Streamlit  

---

## ⚙️ How It Works
1. Load dataset  
2. Train machine learning model  
3. Take user input  
4. Predict ticket price
